# Royal Bites — Demo

Premium responsive restaurant website demo built as a static frontend.

## Run locally
Open `index.html` directly, or use a local server such as:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Deploy
Push this folder to GitHub and import the repository into Vercel. No backend is required for this demo.

## Before client delivery
Replace the placeholder phone number, address, Instagram URL, Google Maps URL, menu prices, and image URLs with the client's real information. For production, replace the WhatsApp number in `script.js` too.
